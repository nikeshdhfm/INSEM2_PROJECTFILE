# Like Button

A simple front-end Like Button built with HTML, CSS, and JavaScript.

## Features

- Click **Like** to increase the count by 1.
- Click **Liked** again to unlike and decrease the count by 1.
- Updates the count instantly without reloading the page.
- Responsive, centered layout.

## Run locally

1. Download or clone this repository.
2. Open `index.html` in your web browser.

## Technologies

- HTML
- CSS
- JavaScript

## Note

This is a front-end demonstration. The like count is stored in JavaScript memory, so it resets when the page is refreshed. A backend or browser storage would be needed to persist likes.
